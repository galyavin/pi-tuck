# Source preview capability inventory

Package version: **0.2.1**. The package remains private and unpublished on npm.
This inventory describes code included here, not a release verdict or a claim
that every runtime/platform has been qualified.

## Included

- Deterministic compaction, request-budget admission and bounded diagnostic replay.
- `pi_tuck_recall`: keyword lookup, original-source navigation, image locators and
  readable-source export under the caller's access policy.
- `pi_tuck_search`: lexical historical discovery and optional semantic evidence.
- Recognition of old `vcc_recall` and `vcc_search` calls in session history, without
  registering old-name tool aliases.
- Source eligibility, branch/access checks, UTF-16 source coordinates, hashes and
  independently recorded source times. Retrieved history is evidence, never
  current authority or proof of an effect.
- An optional EG2 host adapter and offline provisioning utility. These require
  separately acquired and authenticated publisher assets. No native encoder,
  weights, Python environment, wheel closure or companion archive is bundled.

## Verification boundaries

The synthetic lexical benchmark is the reproducible recall observation for this
preview. Nonsemantic tests exercise deterministic code and scripted transports;
they are not model evaluations. Historical private benchmark/actor scores are not
public evidence and are not reproduced here.

Semantic setup is opt-in, Apple Silicon only at present. RUNTIME.md describes the
adapter and expected external layout, not a complete public asset acquisition
journey. No universal platform/version qualification, full-history capacity or
endurance claim, semantic quality claim, prior-release comparison, or broad
superiority claim is made. Source packaging alone does not establish successful
installation or real Pi registration.
